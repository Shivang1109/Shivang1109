* 🤖 Agentic scam interaction
* 🔎 Automated intelligence extraction
* 📱 Phone number and UPI identification
* 🧠 NLP-based analysis
* 🗄️ Structured intelligence storage
* 🐳 Dockerized backend

**Tech Stack:** `TypeScript` `Express.js` `PostgreSQL` `Docker` `NLP`
